## Q3 (T01) 我自行决定的几件小事，请追认

任务包没写、但不决定就做不下去的地方，我按最小合理方案处理了：

1. **面包屑单级时不渲染**。首页面包屑是「首页」，和顶栏导航里的「首页」视觉重复，
   截图上看像两个导航项。改成只有二级及以上才显示。
2. **「距考试 -- 天」在 375px 也保留**。原本我按窄屏隐藏，但倒计时是核心激励元素，
   藏掉是产品损失。改成收紧内边距，全宽度显示，e2e 已断言可见。
3. **主 CTA「开始今天的任务」暂链到 `/vocab`**。任务包没指定目标页，背词是每日固定动作，
   先指这里。等 M6 的自动计划做出来后应改指当日任务页。
4. **lint 用 `eslint .` 而非 `next lint`**。后者在 Next 16 被移除，且已打印弃用警告。
5. **e2e 跑 dev server 而非生产构建**。快得多；生产构建在验收里由 `pnpm build` 单独把关。
6. **不引入网络字体**，用系统字体栈。既避开构建期外网依赖，也帮首屏预算。
