# 研英猫 (readmeow.top) 结构拆解 → 雅思版开发简报

> 用途：交给 Claude Code 作为项目起点。原站是朋友的考研英语学习站，已获授权参考其结构做雅思版本。
> 来源：2026-09-07~09 实际登录并逐功能测试所得（账号已激活）。未拿到源码，以下技术细节为前端观察 + 推断；若朋友能直接给 repo，以 repo 为准。

---

## 0. 一句话定位

原站 = **"在真题里学"的闭环**：真题精读（逐句译文+词义+长难句）→ 背单词（间隔复习）→ 真题作答（分板块/整套）→ 答后解析 → 错题本/句子收藏 → 统计/计划。
雅思版沿用这个闭环，把"考研真题"换成"雅思四科"，并补上原站没有的**听力、口语、写作批改**。

## 1. 原站技术栈（观察）

| 项 | 观察结果 |
|---|---|
| 前端 | 原生 JS 单页应用，挂载点 `#app`，无 React/Vue 痕迹；路由由 JS 内部状态切换，URL 始终是 `/`（无 hash/path 路由） |
| 资源 | `app.js`(~175KB) + `assets/study-planner-core.js` + `study-planner.js` + `home-plan-cube.js`；6 个 CSS 拆分文件（`styles.css`、`cift-theme.css`、`cift-learning.css`、`cift-workbench.css`、`cift-dark.css`、`study-planner.css`），全部用 `?v=xxx` 手动 cache-busting |
| 3D | 首页右侧小方块用 three.js（204KB），纯装饰 —— **雅思版不要复刻** |
| 后端 | 有 REST API：`/api/auth/me`（未登录 401）；设置、背词记录、答题记录、收藏均"按账号保存在服务端" |
| 鉴权 | 邮箱+密码注册；登录后需**激活码**解锁功能（访客只能看真题原文） |
| 部署 | HTTP/2，gzip，`lang=zh-CN`，无 SSR |

**雅思版建议栈**：Next.js/Nuxt 或 Vite + 任一轻框架，真实路由（`/reading/cam18-t1-p2`），Supabase/Postgres 存用户数据，静态题库 JSON。

## 2. 信息架构（页面/功能清单）

### 2.1 全局壳
- 顶栏：汉堡菜单 | Logo+站名 | 面包屑（"首页 / 功能面板"、"阅读 / 内容目录"） | **距考研 N 天** | 反馈 | 登录/注册 或 头像
- 头像下拉：显示名 + 激活状态 | 句子收藏夹 | 错题收藏夹 | 学习设置 | 退出
- 汉堡菜单（学习导航）：返回首页 | 阅读目录 | 题型目录 | 统计/计划 | 提交反馈 | 刷新今日队列 | 重置本次计时 | 退出
- 底部悬浮 Tab（5 个）：首页 | 背单词 | 句子收藏 | 错题收藏 | 统计
- 全局搜索框："搜索单词、年份、试卷类型或题型"
- 公告条（可关闭）、更新日志（首页底部，逐条折叠）
- 明/暗主题切换；像素猫吉祥物（点击有动效）

### 2.2 首页
- 提示文案 + 主 CTA（登录后开始）
- "今日计划"入口（3D 方块）
- 两张主线卡片：**主线一·阅读（进入真题精读）** / **主线二·真题（开始真题作答）**
- 最近学习卡片（继续上次）
- 更新日志

### 2.3 学习设置
- 每日新词数量（默认 30）
- 词书选择（考研核心 6513 / 红宝书 6550）+ 起止序号范围
- "我已背完一轮以上"开关（全部标已学，进入全库复习）
- 导入自定义词书（TXT，每行一词）
- 记忆节奏：固定间隔 1/2/4/7/15/30/60/120 天；每组 ≤7 词；不认识的词下一轮再出 + 约 10 分钟短间隔
- 读音设置：美/英音、音色、语速（Web Speech API，本设备保存）
- 词库浏览：全部/已学习/未学习/太简单 筛选 + 分页（50/页）

### 2.4 背单词（卡片流）
- 顶栏：复习 N · 新学 N | 返回 | 倒计时 | 计时器 | 更多
- 卡片：单词 + 发音按钮 + "太简单"标记 + 音标；默认**隐藏释义**，先凭印象选"认识/不认识"
- 翻开后：释义（按词性）、英英释义（折叠）、词根构词、例句 → "下一词"
- 进度：`1 / 7`（每组 7 词），"第 N 轮，顺序已随机打散"

### 2.5 真题精读（阅读中背单词）
- 文章选择器（156 篇，2005–2026 英一/英二各 Text）
- 正文逐句排版：**词下小字释义**（黄色高亮）+ 每句下方中文译文
- 段落标签（Paragraph 1…）
- 长难句：句下显示"结构笔记"（如"被动主句加 with 复合结构含同位语从句"）+"句子骨架"（一句话中文骨架）
- 指代提示（显示代词指向）
- 右下悬浮球 → "阅读工具"面板：计时器开关 | 隐藏词义提示 | 标注色 | 显示长难句(N) | 显示指代(N) | 隐藏译文 | 选择句子 | 句子收藏夹
- 选中句子可加入"句子收藏夹"（卡片式，可叠放切换）

### 2.6 真题作答
- 双栏（上：原卷区可滚动，中间拖拽分隔条；下：作答区）
- 作答区：题号 + 题干 + A/B/C/D 选项按钮；"已作答 N / M"
- 悬浮球 → "真题工具"：计时 | **作答范围（当前板块 / 整套模拟）** | 试卷选择（2005–2026 英一/英二） | 板块（完形 20 题 / Text1–4 各 5 题 / 七选五 5 题） | 原文辅助（显示译文/隐藏词库提示/标注色/长难句/指代） | 重做本板块 | 提交本板块 | 返回首页
- 板块作答有独立保存/评分/错题/完成记录，不影响整套模拟
- 提交后：得分 `4 / 5 分`，每题标 正确/错误 + 题型标签（主旨/细节/推理）
- **答后解析（全站最强部分，务必复刻）**：
  - 正确选项依据（中英对照 + 一句话理由）
  - "框出原文"（跳回原文定位句）
  - 错误选项逐个分析，并标错误类型：无中生有 / 偷换概念 / 范围扩大 / 主次混淆 / 答非所问 / 绝对化
  - 错因自选：词义不清 / 定位错误 / 推理错误 / 选项辨析 / 粗心漏读 / 时间不足
  - "收藏错题"一键入错题本

### 2.7 错题收藏夹
- 列表 + 筛选；每题卡片：年份/卷别/题号/题型 | 题干中英 | 四选项 | 我的答案 | 查看解析 | 回到真题原文 | 删除
- 分页 `1 / N`

### 2.8 句子收藏夹
- 从阅读里收藏的句子，卡片叠放队列，可切换、翻面看译文

### 2.9 统计 / 计划
- 统计：日期范围筛选（近 7 天…）| 学习时长曲线（按 背单词/阅读/真题 分色）| 阅读错误率环形图（按题型拆分：推理/细节/主旨，错 x/共 y）| 真题做题记录（选试卷+题型，记录刷到第几轮）
- 计划：月历 + 日/周/月/年视图 + 新增计划（手工待办，未与学习数据联动）

## 4. 原站已知问题（雅思版不要复刻）

**功能/设计**
1. 真题作答模式默认显示词义提示（等于开卷）—— 雅思版考试模式**必须**默认关闭一切辅助，交卷后再开放
2. 阅读页头部占半屏，正文在内嵌滚动框里 —— 进入文章后折叠头部或整页滚动
3. 词义提示过密（Everybody/learn/even 都标）—— 按词频分级，默认只标高阶词
4. 悬浮工具面板操作后不自动收起，挡住内容
5. 单词卡大量"词根待补充/暂无例句" —— 雅思版例句直接从题库原句抽取
6. 记忆算法只有固定间隔 —— 建议 FSRS 或简化 SM-2
7. 计划页与学习数据不联动 —— 应由考试日期自动生成每日计划

**Bug**
8. 平板宽度（~600–768px）首页 `.home-intro-copy` 在 flex row 下宽度为 0，文字竖排
9. 手机端像素猫遮住公告条
10. 统计页泄漏占位文案 "MONO CURVED WAVE / Soft Gradient"、"MONO ROUNDED DONUT"
11. 首页最近学习显示内部 ID `common-2005`
12. 统计 X 轴日期截断（"0 日 1 日"），"近 7 天"却画 30 个点，平滑曲线过冲为负
13. 底部导航首次点击常无响应
14. `/api/auth/me` 登录后仍 401（控制台反复报错）
15. 首页 1.6MB：两张像素猫 PNG 共 ~950KB、three.js 204KB 只渲染一个装饰方块

**性能/工程**
- 6 CSS + 4 JS 串行加载、手动 `?v=` —— 用打包器
- 无真实路由，刷新即回首页，无法分享某篇文章链接

| 原站模块 | 雅思版对应 | 备注 |

| 真题作答（完形/阅读/七选五） | Reading 作答：13–14 题/篇，**题型扩展**：TFNG / YNNG / Matching Headings / Matching Info / Summary Completion / Sentence Completion / MCQ / Short Answer | 作答控件不再只是 ABCD，需要 输入框 / 下拉 / 拖拽匹配 |
| —（原站无） | **Listening**：Part 1–4，音频播放器 + 逐句 transcript（可隐藏）+ 答题 + 原速/0.8x + 精听逐句循环 | 新增 |
| 作文（原站无） | **Writing**：Task 1（图表/流程/地图/信件）+ Task 2；限时写作（20/40 min）；**私有模板库**（骨架句/槽位/个人句三层，组合生成 + 重合度提示 + 挖空默写）；AI 批改（按 TA/TR、CC、LR、GRA 四项给 band） | 付费点 |
| —（原站无） | **Speaking**：Part 1/2/3 题库（按季度题库更新）+ 录音 + 1 分钟准备计时 + AI 转写评分（Fluency/Lexical/Grammar/Pronunciation） | 新增 |
| 得分 4/5 | 原始分 → **Band 换算表**（L/R 各自 40 题 → 0–9），四科均分取 0.5 位 | 必做 |
| 错题本（题型标签：主旨/细节/推理） | 错题本（题型标签：TFNG/Heading/…；错因：定位/同义替换/否定词/时间不足） | 同结构 |

| 句子收藏夹 | 句子收藏 → 一键"改写为写作句"存入模板库 | 打通阅读→写作 |
| 统计（时长曲线/错误率环） | 四科分开统计 + 预估 band 走势 | |
| 计划（手工日历） | 由考试日期 + 目标分自动生成每日任务，打钩 | 联动 |

## 6. 版权提醒（雅思 ≠ 考研）

考研真题是国家考试试题，全网公开转载惯例成熟；**剑桥雅思真题（Cambridge IELTS 4–20）是剑桥大学出版社版权内容**，公开站点整本搬运有被投诉/下架风险。做着玩、私用没问题；若要公开：
- 题库改为"用户自行导入"（粘贴原文 → 系统自动分句/生成译文和词义）
- 或自制/改写题目，只保留题型结构
- 词表、题型解析、模板、批改逻辑都是自研内容，无风险

## 7. 建议 MVP 顺序

1. **壳 + 账号 + 设置 + 倒计时 + 词书/背词**（复用原站结构，2 周）
2. **Reading 精读 + 作答 + Band 换算 + 解析/错题本**（题型控件是主要工作量）
3. **Listening**（音频 + transcript + 精听）
4. **Writing 私有模板库 + 限时写作 + AI 批改**（付费点）
5. **Speaking** 题库 + 录音 + AI 评分
6. 统计/自动计划 联动

每一步都先做"内容 JSON 结构 → 页面 → 记录持久化"，别先做动效和吉祥物。
